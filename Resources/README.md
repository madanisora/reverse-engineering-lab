# Resources for reverse engineering and security practice

A short directory of practice environments, competition discovery, and vulnerability-research platforms. These categories are different; using a practice platform is not the same as participating in an official competition or testing a real program.

## Independent practice and labs

- [crackmes.one](https://crackmes.one) — reverse-engineering challenges.
- [picoGym](https://play.picoctf.org/practice) — self-paced CTF practice.
- [ROP Emporium](https://ropemporium.com) — return-oriented programming exercises.
- [pwnable.tw](https://pwnable.tw) — binary exploitation challenges.

## Official CTF discovery and competitions

- [picoCTF](https://picoctf.org) — CTF events and practice material.
- [CTFtime](https://ctftime.org) — event calendar and competition information; a profile or team rating is not an individual certificate.

## Vulnerability disclosure and bug bounty

- [HackerOne](https://hackerone.com)
- [Bugcrowd](https://bugcrowd.com)

A platform account does not itself authorize testing. Read each program's scope, exclusions, rate limits, safe-harbor terms, and disclosure rules before interacting with a target. Do not test out-of-scope systems.

## Cost and publication notes

Check current access, account, and program terms before relying on any service as a free resource. Some bug-bounty programs are invitation-only or have eligibility requirements. Follow each challenge platform's publication rules; do not publish flags, solutions, private data, or third-party binaries where prohibited.
